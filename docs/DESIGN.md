# 研究设计与计分模型

## 1. 系列与结构

Euclid-Equal-Angle-Min 是尺规作图优化系列第三个项目。前两个为 Euclid-Min（正十七边形）和 Euclid-CCC-Min（阿波罗尼乌斯问题）。结构参照 Euclid-CCC-Min 的 `docs/`、`experiments/`、`tests/`、`animations/`；另加 `sources/` 保存本题原始问答。

规则语义参照 Euclid-Min 固定版本：

- [METRICS](https://github.com/lenovobenben/euclid-min/blob/792619b38d749643bc9d80da8110dc9cff5b4877/docs/METRICS.md)
- [FORMAL_MODEL](https://github.com/lenovobenben/euclid-min/blob/792619b38d749643bc9d80da8110dc9cff5b4877/docs/FORMAL_MODEL.md)

沿用基础操作与计费语义，免费输入和目标由本项目单独定义，不继承其他题目的输入对象。

## 2. 输入域与目标

规则配置暂定 `collinear-four-equal-angle-e-v1`。免费输入为 A、B、C、D 四个不同的有序共线点及其完整直线 l。原点、单位长度、圆、非共线参考点不免费提供。

完整参数族为 a,b,c>0；由 [EXISTENCE](EXISTENCE.md) 的独立证明，有解域为 D={a,b,c>0 且 3ac>b(a+b+c)}。D 上恰有两个镜像解，代数推导中的 ac−b² 始终严格为正。

| 目标 | 完成要求 |
|---|---|
| `EA-ONE` | 指定半平面内至少一个满足原始等角目标的点，来自合法对象的有限实交点 |
| `EA-ALL` | D 上全部有限直线外目标点均已成为可用交点；须有完备性证明 |

目标点若只由公式计算得出，尚未作为交点产生，不算完成构造。目标命中不要求绘制其与 A、B、C、D 的连线。

单解与全部解分别记分。若某条程序同时取得全部解，它可为两个目标提供上界，但不能据此断言两种最优值相等。

## 3. 基础操作与 E

`Line(U,V)`：已有 U≠V，画完整直线，1 E。

`Circle(O,Q)`：已有 O≠Q，以 O 为圆心经过 Q 画圆，1 E。半径端点之一必须是圆心，不允许直接使用任意异地长度。

每次落笔后，新对象与所有已有不同线、圆的全部有限实交点自动进入状态。交点和别名为 0 E；确定分支须可精确复现。不同名可能指向同一点；重合对象须管理别名，不能把重合对象的无限交集当作任意取点入口。

不使用任意辅助点、无穷远点或免费复合工具。中点、垂线、平行线、对称点、长度搬运等必须展开。重复执行画线或画圆仍计 1 E；直接引用已有对象不新增 E。正式 E 为完整程序实际执行的画线和画圆动作总数。

原题已给直线 l；若研究只有四点的输入变体，须另设规则配置，并重新计入需要实际画出的 l，不能混合排名。

## 4. 覆盖口径

- `gen`：覆盖 D 中明确给出的相对开稠密、满测度子域；排除条件须明确，不能仅选取一片容易区域。
- `rob`：程序或有限个精确分支覆盖整个 D，成本取最坏情况。

明确只覆盖 D 的真子域、且漏掉有内部区域的程序另记 `restricted`，须给出完整子域条件，不能将其成绩放入整个 D 的 `gen` / `rob` 表。原作图已在 [BASELINE](BASELINE.md) 的 D_original 上验证为 10 E，属于此类。

原作图的两对辅助圆要求 b<2a、b<2c，有限定心点还要求 a≠b、b≠c。这些条件已证明，不能据此缩小 D 并仍声称全域。中间切触、点合并、直线平行、零分母与重合对象分别记录。无解输入的判定纳入存在性研究；构造上界只在相应有解域上报告。

## 5. 结果与证据

| 证据等级 | 可声明的结论 |
|---|---|
| 原文或人工动作清单 | 待核查命题、候选预算 |
| 多样本浮点筛查 | 预筛结果、待精确复验候选 |
| 固定实例精确重放 | 该实例的合法程序和 E 分数 |
| 一般参数恒等式与分支证明 | 明确适用域上的构造正确性 |
| 适用域覆盖证明 | 对应 `gen` / `rob` 的正式上界 |
| 完备排除或理论下界证明 | 所声明模型与范围内的下界 |

固定实例、数值命中或有界搜索未命中都不能单独成为全局最短证明。不存在已验证构造时，正式分数记 `null`，不用名义预算填充。

未来结果至少记录：规则版本、目标、覆盖标签、输入或适用域、线与圆动作数、总 E、目标首次出现时刻、依赖与复用、命令、证据位置和未覆盖退化。

## 6. 工程安排

采用独立 Python 研究脚本，与参考项目一致，不预先引入完整应用框架。精确判定优先有理数与可审计的代数表示；数值搜索与动画坐标不承担证明责任。可视化只读取验证后导出的几何轨迹。

脚本前缀沿用 `replay_`、`verify_`、`search_`、`scan_`、`audit_`。每个搜索实验须声明初态、候选范围、预算与停止条件，结果保存到 `experiments/results/`。当前已提供存在性与原作图的 SageMath 符号核验、AA 精确重放、自动交点闭包和依赖记录，尚未实现搜索器或动画。
